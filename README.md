Create a LUXURY PATISSERIE & CATERING website.

- Premium
- Elegant

- Warm
- French/Moroccan luxury
- High-end pastry boutique
- Editorial food photography
- Minimal but visually rich
- Strong visual hierarchy
- Lots of whitespace
- Smooth animations
- Excellent mobile experience

Color palette inspired by the existing Merry Prestige logo:
- Warm beige / champagne
- Soft cream
- Deep espresso brown
- Subtle black
- Elegant gold accents

The combination should feel like a premium French pâtisserie brand.
